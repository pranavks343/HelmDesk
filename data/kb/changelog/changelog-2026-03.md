Released March 2026. New: SCIM deactivation sync is now five minutes on Enterprise. New: bulk endpoints accept up to one hundred items per request. Improved: backup restore into a new workspace is twice as fast. Fixed: invoices showed the wrong tax line for annual plans in some regions. Fixed: webhook retries stopped after four attempts instead of eight. Deprecated: API v1 tokens will stop working on 1 October 2026; migrate to workspace API keys. Known issue: the dashboard may show stale seat counts for up to two minutes after a change.
