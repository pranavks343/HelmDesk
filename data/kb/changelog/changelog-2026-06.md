Released June 2026. New: audit log export to CSV for Enterprise. New: webhook event for backup completion. Improved: SSO error messages now include the failing SAML attribute and error code E110 guidance. Improved: error responses include a request id to speed up support. Fixed: manual backups were incorrectly counted toward the daily backup schedule. Fixed: refund confirmation emails were delayed by up to an hour. Security: rotated default signing secrets for webhooks created before 2025; existing webhooks keep working.
